# Kerbal Port for Kitten Space Agency

Adds the Kerbal from Kerbal Space Program as a playable crew character in KSA: body, helmet, visor, jetpack (the game's own MMU), and KSP's own animations.

## Install

1. Copy this whole folder (`KerbalPort`) into `Documents/My Games/Kitten Space Agency/mods/`.
2. Start the game. It detects the new mod by itself.

That is all. Kerbals join the pool the game draws crew from, next to the kittens, so new crew members are a random mix. Saves that already exist keep the characters they have.

If the Kerbal does not show up, open `Documents/My Games/Kitten Space Agency/manifest.toml` and make sure the `KerbalPort` entry has `enabled = true`.

## Contents

* `KerbalAssets.xml`: the character definition (Id `Kerbal`).
* `Characters/Kerbal/`: body, helmet, visor and the animations, one file per KSP clip (slots that play the same clip share it).
* `Textures/`: the Kerbal's textures, plus the jetpack textures copied from the game so the folder works on its own.

## Credits and legal

The models, textures and animations come from Kerbal Space Program (Squad / Intercept Games, Take-Two Interactive). The jetpack is Kitten Space Agency's (RocketWerkz). This project is a fan port and is not affiliated with either.

The files are generated by a converter (kept in a separate repository), so please do not edit them by hand.

## Known limitations

See the converter's `backlog.md`. Short version: the jetpack keeps one floating pose whatever the thrust (as in KSP), the face has no expressions or blinking yet, and the Kerbal's eyes follow the camera like the kittens' do (that is the game's behaviour).
